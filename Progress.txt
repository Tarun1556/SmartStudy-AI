GENAI REQUIREMENT
==================================================

This is a GenAI project.

Do NOT leave the application in a state where the main AI
experience is generated by deterministic mock logic.

Implement a clean provider abstraction:

LLMProvider
    ├── AnthropicProvider
    ├── OpenAIProvider
    ├── GeminiProvider
    └── MockProvider

The active provider must be selected using environment variables.

Use structured JSON responses for:

- lecture notes
- topic extraction
- quiz generation
- grounded Q&A where appropriate

Validate all structured AI output using Pydantic.

If an API call fails:

1. retry safely where appropriate
2. validate the response
3. show a useful error
4. do not silently pretend mock output is real AI output

MockProvider may remain available for testing, but it must not be
the default production/demo intelligence when a real API is configured.

IMPORTANT:
A Claude Pro consumer subscription is NOT automatically an
Anthropic API credential.

Use a real API credential only when available in environment
configuration.
